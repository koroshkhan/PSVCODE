# PS5FileDump (Windows Release)

نسخه اختصاصی و بهینه‌شده برای ساخت سریع خروجی ویندوز (`PS5FileDump.exe`) از طریق GitHub Actions و Releases.

### امکانات برنامه
- تحلیل سلامت و سازگاری PS5 برای هر فایل (با هر پسوندی یا بدون پسوند)، پوشه بازی و فایل‌های `.zip`
- بررسی هدر 64-bit ELF فایل `eboot.bin`، خواندن `param.json`، کنترل `fakelib/libSceAmpr.sprx` و محاسبه `SHA-256`
- تبدیل استریم واقعی بین فرمت‌ها و آرشیوها با نوشتن اتمی `.part` و راستی‌آزمایی سایز
- پک و آنپک دارایی‌های بازی با `Zstd` و `LZ4` همراه با ایندکس ۸ بایتی `ampr_emu.index`
- ویرایشگر فایل دامپ با امکان Undo و اعمال ایمن تغییرات، مدیریت کتابخانه و ارسال Payload به پورت `9021` کنسول PS5
